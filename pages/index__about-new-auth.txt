# О Яндекс ID
Что это
Единый аккаунт для всех сервисов Яндекса — нужен для входа в личный кабинет.
Почему это удобно
Управление доступом сотрудников через один кабинет.
Один Яндекс ID для разных личных кабинетов.
Безопасный вход по номеру телефона.
# Создание Яндекс ID
Для новых пользователей
Нажмите Создать ID на странице входа .
Введите номер телефона → Продолжить .
Введите SMS‑код подтверждения.
Укажите имя и фамилию.
Придумайте логин .
Создайте надёжный пароль.
Примите пользовательское соглашение → Готово .
# Вход в личный кабинет
Шаги
Перейдите на страницу входа .
Введите логин и пароль вашего Яндекс ID. В качестве логина используйте почту или номер телефона.
Подтвердите вход при запросе через SMS или пуш‑уведомление.
Альтернативный вход
Нажмите Войти по телефону .
Введите номер и получите SMS‑код.
Выберите нужный Яндекс ID из списка.
# Управление пользователями
Примечание
Настройка ролей Управляющий и Оператор доступна в разделе 1.2 .
# Добавление пользователя
Войдите в аккаунт → Профиль → Управлять аккаунтом .
На вкладке Пользователи нажмите Пригласить пользователя → введите почту сотрудника.
На почту придёт приглашение с инструкцией по привязке Яндекс ID — ссылка будет действительна в течение 3 дней.
# Удаление пользователя
Во вкладке Пользователи выберите сотрудника → значок корзины 🗑️.
Создайте обращение в поддержку для подтверждения.
# Решение проблем
# Если забыли пароль
На странице входа → Не помню пароль .
Введите логин и пройдите проверку → укажите телефон и введите SMS‑код.
Введите новый пароль.
# Если не приходит SMS с кодом
Убедитесь, что номер телефона введён правильно.
Если всё верно, нажмите Отправить ещё раз , чтобы запросить код повторно.
Проверьте папку со спамом на устройстве — иногда сообщение может попасть туда.

# Как изменить название личного кабинета
В боковом меню нажмите на свой аккаунт, появится всплывающее окно и кнопка Управлять аккаунтом .
В блоке Личный кабинет нажмите на карандаш — поменяйте название.
Оно будет отображаться только для вас. Другие пользователи его не увидят, даже если имеют доступ к личному кабинету.
# Как сменить личный кабинет
В боковом меню нажмите на свой аккаунт, появится всплывающее окно и кнопка Управлять аккаунтом .
В блоке Личный кабинет около названия кабинета появится кнопка Сменить кабинет — нажмите на неё.
Вы попадёте на страницу со списком личных кабинетов, привязанных к этому ID — выберите нужный.
Если вы заметили ошибку в справке или у вас есть предложение, что можно улучшить, напишите нам через форму обратной связи. Пожалуйста, опишите ошибку или идею как можно подробнее.
